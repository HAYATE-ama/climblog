# ClimbLog 全体レビュー・改善報告（2026-10-28）

## 方針と確認範囲
日々の記録を少ない操作で残し、詳しい条件は必要なときに開く。これまで承認されたホーム、月間カレンダーと右側の詳細、いつものメニュー、縦並びの設定ドロワー、ライト／ダークを維持する。

対象は本番リポジトリの画面、記録・トレーニング・統計・身体情報・ジム設定・天気・認証／同期の実装と既存テスト。個人の本番DBや秘密ファイルは閲覧・変更しない。以下は今回確認できた改善点であり、すべての潜在的不具合を発見したという意味ではない。

## 今回反映した改善

|場所|変更前・問題|変更後|
|---|---|---|
|カレンダー|31日を基準に次月へ送ると2月などを飛ばす|月初を基準に移動。月末、うるう年、年またぎを検証|
|記録検索|30件で打ち切られ、続きがない|30件ずつ追加表示。全件に到達できる|
|記録検索|件数・絞り込みの操作が分かりづらい|総件数と表示件数、検索欄／活動選択の読み上げ名を追加。条件変更時は先頭30件へ戻す|
|表示・カレンダー設定|週の始まりの設定がドロワーへ移されず操作できない|テーマと週の始まりを同じ設定内に表示。保存・再読込を確認|
|トレーニングのカード|種目変更や説明が先に並び、基本の回数・重量まで遠い|セット数・時間／回数・休憩・荷重方法・重量を先に表示。説明や種目変更、セット別設定は後に配置|
|カードの削除|編集欄の最初に削除操作がある|削除を編集欄の末尾へ移動。並べ替えは既存の専用操作を維持|
|完了時|きつさや気づきを記録する機会がない|「きつさ・気づきを残す（任意）」を追加。RPE 1〜10と、テーマに合わせた全幅のメモ欄。入力しなくても保存可能|
|完了時の中断|新しい振り返り入力を失う可能性|端末内の途中記録へ保存。再読み込み後も復元。メニューのテンプレートへは混入させない|
|保存した記録の閲覧|きつさが閲覧画面に出ない|RPEと、それがトレーニング全体の感想であることを表示。既存のメモ欄を利用|
|AIコーチ|内部の「参照できる記録」とロードマップが画面を占める|開発中表示と目的・時間・場所・器具の条件に絞る。内部集計は画面に出さない|
|将来の集計|同じ種目でも自重・追加荷重・地面リフトが混ざる|種目ID・左右・進め方に加え荷重方法を分離。外部重量のサンプル数・最小・最大を追加|
|RPEの集計|1コースに複数種目があると全体のきつさを重複集計し得る|同じセッションのRPEは1件として集計し、種目別RPEとは別の平均にする。不明・未入力は平均へ入れず、相互に矛盾する値は別件数として検出|
|前回コピー|古いタイマーのセッションID・実測時間が新しい記録へ残り得る|元の実測メタデータを外し、前回のRPEも未記録へ戻す。予定内容と新しい実績を混同させない|
|記録の由来|入力方法を識別する専用項目がない|新規手入力にmanual、タイマー保存にtimer、コピーにcopyを記録。過去記録へ推測で書き足さない|
|文字・色の表示|グレード名・一部の統計表示・色をHTMLへ直接埋め込む|文字をエスケープし、色は許可した16進カラーへ制限。試験用のHTML文字列が要素として生成されないことを確認|
|PWA更新|以前の画面資源が残る可能性|Service Workerのキャッシュ世代を更新。既存の更新確認の仕組みを維持|

## 維持した機能・操作

- ホームはキャラクターと短い会話。情報カードを増やさない。
- カレンダーは全活動／外岩／ジム／トレーニング、日付選択、詳細と登録の構成を維持。
- ジムはジム・色付きグレード・完登／敗退・トライの入力と一括記録を維持。
- 外岩はボルダー／リード、グレード体系の切替、NoGrade、課題ごとの記録を維持。
- トレーニングはいつものメニュー、テンプレート、イラスト、左右別・セット別・カード別の重量、並べ替えを維持。
- タイマーの準備、実施／休憩、3・2・1の音、一時停止、復帰、消灯抑制、完了確認を維持。
- 統計の基本配置、文章の目標、外岩シーズンと並べ替え、最大出力、トレーニング量を維持。
- 身体設定の身長・リーチ・体重履歴と、記録時の体重スナップショットを維持。
- 削除／ゴミ箱、履歴、JSONバックアップ、認証・アカウント別データ・クラウド保存を維持。
- 外岩の候補日は既存の気象庁データと前日雨の条件を利用。AIや有料APIを新たに接続しない。

## AI用データの状態

新しい項目の意味、集計の境界と未対応事項は [AI用データ蓄積](ai-data-readiness.md) を参照。AIコーチは開発中のまま。外部送信・APIキーの読取り・API課金を行わない。APIへ接続する前には、サーバー側の秘密管理、利用者の同意、利用量制限、提案の検証が別途必要。
