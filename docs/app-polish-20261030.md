## 採用した変更

|場所|確認した問題|変更前 → 変更後|
|---|---|---|
|記録閲覧|長いセット表では閉じる・編集が画面外になる|通常の末尾操作 → 閉じるヘッダーと編集・削除・再実行フッターを固定|
|記録閲覧|一覧の再描画で閉じた後の操作位置を失う|元の要素が消える → 同じ記録ID・同じ一覧種別の行へフォーカスを戻す|
|記録閲覧|モーダルの背後のスクロール管理がない|ブラウザー標準任せ → 閲覧中は固定し、閉じる・編集へ移る・認証解除で復元|
|トレーニング設定|長いコースの入力エラーが全カードの末尾にしか出ない|理由が画面外 → 上部の1か所に表示し、エラー時だけ位置とフォーカスを案内|
|トレーニング設定|新形式メニューにも旧形式の変換警告が出る|毎回警告 → entries形式の旧メニューだけに表示|
|統計|前後の月・年を比較するたび選択欄を操作する|選び直す → 「前の月／次の月」「前の年／次の年」で1操作。外岩は年単位|
|統計|トライの記録があっても完登グラフが単に「記録なし」と表示する|記録自体がないと誤解 → グラフ対象の実績がなく、元の記録は一覧にあると案内|
|ヘッダー|固定バー越しに背後の文字が透ける|半透明 → 両テーマで不透明な背景|

期間移動は月初を基準に計算し、年またぎ・うるう年・1900〜2200年の境界を検証した。期間を変更してもジム・測定条件・並び替えを保持し、全期間では移動操作を表示しない。統計の数値の計算方法は変更していない。

閲覧から編集へ移る場合は、先に閲覧側の固定を同期解除してから編集画面を開く。遅れて届くcloseイベントが編集画面の固定を解除しないようにする。削除は既存の確認とゴミ箱を維持し、永久削除や自動削除は追加していない。
