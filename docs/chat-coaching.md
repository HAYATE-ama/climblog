# チャットで行うAIコーチング

2026-11-05から、アプリ内のAPIコース生成を終了し、記録をチャットで分析してコースを改修する運用へ切り替える。

## 利用の流れ
1. アプリの「AIコーチ」で対象期間と相談したい目標を入力する。
2. メモ・身体情報・ジム/岩場/課題名を含めるか選ぶ。初期状態はいずれもオフ。
3. 「レポートを作成」で内容を確認し、「相談文と記録をコピー」を押す。
4. このアプリの開発を相談しているチャットへ貼り付ける。長い場合は「テキストを保存」で保存したtxtを添付する。
5. 記録から傾向・不足情報・トレーニングやコースの候補を相談する。
6. 採用する方針を確認した後、種目定義・テンプレートコース等のソース改修としてアプリへ反映する。

このチャットから個人の記録を自動取得しない。コピーするだけでは外部へ送信されず、利用者がチャットへ貼る操作で共有する。
レポートはJSONを含む読める文章。CSVではない。アプリがAIからコースを自動取り込む機能ではない。

## 記録の意味を保つ
日付、種別、グレード、完登/敗退、トライ数、種目名とID、方式、セット、回数、時間、重量と重量設定状態、主観的強度、握り方、左右、エッジ深さ等を許可項目として出力する。
出力にID・アカウント情報・API設定・トークン・同期情報・履歴バックアップを含めない。
メモは選択したときのみ最大2000文字/記録、場所名も選択時のみ。
身体情報を選ぶと体重・身長・リーチ、対象期間の体重履歴を追加する。
0kgの重量なしと、重量の未設定は区別する。未設定はnullと設定状態で表す。
記録のない日は休養と断定しない。違う握り・エッジ・左右・負荷方式の最大値を同条件として比較しない。
出力対象は現在のアカウントの通常記録。ゴミ箱・削除履歴や認証用ストレージを読まない。

レポート生成後に期間・共有項目・記録が変わった場合は作り直す。ログアウト/認証ロック時に画面の出力を消す。
下書きやレポートを新しい永続ストレージへ自動保存しない。コピーが拒否された場合は文章を選択して手動コピー、またはtxt保存を案内する。
実記録や出力txtはGitHubに追加しない。

## APIの停止
ブラウザーのAIコーチ画面は外部APIを呼ばず、従来の同意画面や自動生成を起動しない。
共有トランスポートもai-coachへの要求を通信前にCOURSE_API_RETIREDで拒否する。
Supabaseのai-coach入口は410と停止案内を返すだけの実装とし、旧PWAからも生成・設定書込み・採用送信を行えない。
既存のDB行・記録・コースは削除しない。過去のAPI用モデル/検証コードは既存形式の互換性と他のモジュールからの参照のため保持する。
既存APIのキーを読み出したり、課金設定や別の連携用Secretsを変更したりしない。
