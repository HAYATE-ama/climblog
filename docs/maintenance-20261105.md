# バックアップ復元の選択・確認の修正（2026-11-05）

## 問題と変更
有効なJSONを確認した後、不正なJSONへ選び直すと、以前の確認内容と復元ボタンが有効なまま残る問題をサンプルの画面試験で再現した。不正なファイルが読み込まれた表示なのに、以前の内容を復元できる状態だった。実ユーザーでの発生は確認していない。
ファイルを選び直した時点で読み込み内容・確認結果・復元操作を無効化する。正常に読み込んだ後でのみ再確認でき、確認してから復元する。選択解除や読み込み失敗も同様に扱う。
複数ファイルの読み込み順が逆転しても、最後に選んだファイル以外の完了通知は使わない。別のデータ管理タブへ移動した場合と認証ロック時も、古い読み込み・確認結果を破棄する。読み込み中と不正JSONの案内を日本語で表示し、ファイル欄にラベルと案内の関連付け、状態通知を追加した。
