# 目標から組み立てるAIコーチ（2026-10-30）

## 操作
1. 主目標を1つ、自由記述で入力する。現在の実力・登れる曜日・目標時期などは追加情報へまとめる。
2. 今日使う場所・器具、登る種目、痛み・疲労、希望を入力する。時間の入力は不要。
3. 情報が不足すればAIが最大3問をまとめて返す。追加情報へ回答して再生成する。質問も1回のAPI利用なので、従来の1日2回・利用間隔・月上限をそのまま適用する。自動再試行はしない。
4. 継続方針・週の組み立て・見直す観点を確認して承認する。新しい方針は自動採用しない。
5. 今日の必達メニューと目安時間を確認し、既存の編集・タイマー・カレンダー保存へ進む。生成や方針承認だけでは実施記録を追加しない。

## 必達と安全
全種目・セットが今日の計画の完了条件。確認できた実績が計画量を満たした場合のみ「本日の計画完了」と表示する。未実施は「未実施」、スキップや不足、内容調整があれば「一部実施・内容調整あり」とする。複数回の実行を勝手に合算せず、別日・別提案の記録も混ぜない。過去の実績訂正後は古いセット結果だけで完了判定しない。

痛み・強い疲労では従来どおり生成を止め休養を案内する。安全のため中断やスキップは維持する。必達は計画上の完了条件であり、無理な実施や目標達成を保証する量ではない。未実施分を翌日に積み増さない。最大出力テストや重量の自動増加を提案しない。

## 実装と互換性
継続方針は既存の設定JSONと提案JSONに保存する。追加SQLは不要。目標の変更時は以前の方針承認を無効化し、異なる目標の提案を誤って承認・開始しない。

旧設定・旧提案の形式と時間制限は維持する。新しい目標型では90分を技術上の安全上限として内部で維持するが、AIにはその時間を埋める指示をしない。目安時間は検証済みセット・休憩から算出する。既存の種目・左右・量・時間・無加重の検証を維持する。

今回入力した目標・追加情報・承認済み方針と曜日をGoogleへ送ることを画面へ明示した。無料運用で過去の記録・身体情報を自動送信する仕組みは追加しない。有料運用の既存共有目標が今回の主目標を上書きしない。キー・課金・モデル・上限は変更していない。

## 確認と制約
単体291件成功。目標型の追加8件は別担当が作成し、旧形式、明示した目標だけの送信、質問、承認、目標取り違え、実績訂正を確認。画面は既存AIコーチの320/390/1280pxと両テーマ、失敗・再生成・待ち時間・認証解除・編集・タイマー保存をモックで検証。追加のスマホ両テーマ試験で質問→回答→方針承認→開始を確認した。

実AIへの呼び出しは0回。本番の通常記録・身体情報・アカウントを試験で変更していない。iPhone実機・Gemini実応答での質問品質や継続方針の品質は未確認。既存の確認済み研究ガイダンスを維持し、新しい運動の有効性や全員に必要な量を保証していない。

今回の継続プランは承認済み方針と週の構成を再利用する初期版。無料運用での詳細な履歴に基づく自動調整、週ごとの数値負荷計画、将来日の大量一括生成は追加していない。必要な変化は追加情報に書いて見直し、AIが提案した変更は承認して反映する。
