# トレーニングの状態表示と音

運動中は赤系、セット間/種目間の休憩は緑系の大きな背景と状態名で区別します。準備・一時停止・結果確認は中立色。ライト/ダークでそれぞれ文字とのコントラストを確保し、色だけに意味を持たせません。点滅・常時アニメーションはありません。次の動作に種目とセット番号を表示します。

## 通知
- タイマー音は初期オン。開始前の「記録・タイマー設定」または実行中の音ボタンで切り替えできます。選択はその画面セッション内のみで、メニューやクラウドの形式は変更しません。
- 準備、時間式運動、休憩の残り3・2・1秒で短音。回数式の運動は終了時刻がないので予告音を鳴らしません。
- 運動開始と休憩開始は別の音程・長さ、全工程終了は2音。途中終了は全工程終了の音を鳴らしません。
- 同じ工程・同じ残り秒の音は1回。一時停止・再開で同じ秒を再生せず、遅延時に過去の音をまとめて鳴らしません。休憩を延長した場合は新しいカウントダウンとして予告できます。
- 運動/休憩が3秒以下の場合、開始の切替音をその開始秒の通知として扱い、重ねて予告音を鳴らしません。
- オフ・一時停止・画面移動・中断時は予定音を止めます。結果の保存・実績・二重保存防止・消灯抑制は維持します。

## 端末の制約
Web Audioはユーザーの開始/再開/音ボタン操作で有効化します。利用不可・権限拒否・中断状態では画面に案内を出し、音をオフ→オンに切り替えると再試行できます。音の有効化が失敗しても運動は画面で進行できます。音量や消音、ブラウザー制限により実際に聞こえるかをアプリだけで判定できません。1秒以内に有効化できなければ待ち続けず案内します。バックグラウンドは既存方針どおり一時停止し、バックグラウンド再生を保証しません。

## 検証
単体で3・2・1秒、繰り返しtick、停止/再開、工程切替、休憩延長、遅延、回数式、利用不可/再試行、音のパターンと停止を確認。ブラウザで320/390/1280px、両テーマ、準備→運動→休憩→運動→完了→保存、一時停止、音オフと利用不可を確認。音はテスト用AudioContextで発音要求を検証し、スピーカーやiPhone実機での聴取確認は未実施です。
