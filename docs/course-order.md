# コース内の種目の並べ替え

コースを選択 → メニューを確認 → 種目一覧の「並べ替え」。各カードの上部に「↑ 上へ」「↓ 下へ」が表示される。カードを開く必要はなく、スマホでも44px以上のボタンを押して変更できる。先頭の上移動・末尾の下移動は無効。終了すると通常のコンパクトな一覧に戻る。

種目のオブジェクトごと移動するため、左右・イラスト・種目ID・個別セットの回数/秒数/重量/休憩を保持する。移動後も対象カードへフォーカスとスクロールを追従し、移動結果を読み上げる。編集中の開閉状態は種目IDに紐づけて維持する。順番以外のタイマー仕様は変更しない。

「いつものメニューに保存」で順番をクラウド同期対象の既存メニューへ保存。保存せず開始した場合はその実行だけに適用する。登録済みテンプレートや過去の記録は書き換えない。実行中の種目の順番は変更できない。

検証：workout-order.test.mjs、browser/course-order.mjs。左右を含む移動、先頭/末尾、入力の保持、保存・再読み込み、タイマーの開始順、ライト/ダーク、320/390/1280幅を確認する。iPhone実機未確認。
