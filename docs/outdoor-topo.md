# 課題の写真・トポ

2026-11-21追加。外岩の課題に、自分で選んだ写真とライン・スタート（S）・ゴール（G）・メモを紐付ける。外部アップロード、AI処理、課金は行わない。

## 使い方

1. ホームの「登りたい課題」から課題名を開き、「写真・トポを見る / 追加」を押す。保存済みの外岩記録の詳細からも開ける。
2. 「写真を追加」で写真を選ぶ。「ライン」は順にタップするか指でなぞる。「S スタート」「G ゴール」は位置をタップする。
3. 「ひとつ戻す」「ひとつ進める」で編集を取り消す・やり直す。連続して描いた1回のジェスチャーを1操作として扱う。戻した後に別の編集をすると、その先のやり直し履歴は消える。
4. 「写真・マークを保存」で端末に保存する。写真だけでも保存できる。「キャンセル」は保存前の状態に戻す。
5. 「写真のみ」でマークの表示を切り替える。複数写真がある場合は写真を選択できる。

「保存済みの写真を使う」で同じ岩場の写真を別課題にも紐付けられる。マークとメモは課題ごとに独立し、同じ写真の別課題は選択欄から切り替えられる。選択中はオレンジ、他のラインは白い点線。

キーボードでは編集する写真にTabで移動し、矢印キーで位置を変え、Enterで配置できる。Shift＋矢印は細かい移動。テキスト欄以外ではCtrl/Cmd＋Z、Shift＋Ctrl/Cmd＋Zも利用できる。保存・キャンセル後は編集履歴をリセットする。

## 保存と互換性

- 写真本体：IndexedDB `climblog-topo-photos-v1` / `photos`。既存のローカル保存先IDと写真IDの組で分離する。
- 課題・写真の紐付けとマーク：`climbLogOutdoorTopos`、版1。通常の一括保存処理を利用する。ライン等の座標は0〜1で保存するので表示幅に依存しない。
- 元ファイルを変更せず、アプリ用のコピーを長辺最大1920pxのJPEGに変換する。写真の位置情報等のファイルメタデータは引き継がない。元の解像度を保存する機能ではない。
- JPEG・PNG・WebPを受け付ける。HEIC/HEIFはブラウザーでデコードできる場合のみ。非対応時はJPEG等の選択を案内する。入力は30MBまで、変換後4MBまで。
- 写真IDは変換後画像のSHA-256。同一内容は同じ保存先で共有し、画像は上書き編集しない。課題名・岩場・エリア・種目が一致するものを同じ課題とし、グレード変更では紐付けを変えない。名前やエリアを変更する操作への追従は今回の範囲外。
- 写真を書き込んでから紐付けを保存する。紐付け保存失敗時は既存情報と編集内容を保持する。中断により未参照の画像が残る場合があるが、自動削除は行わない。
- 写真の追加やマーク編集で登攀記録・成否・段数は変更しない。
- 未保存の閉じる操作は確認する。タブやOSの強制終了で未保存編集が残る保証はない。

## 任意のバックアップ

既存のJSON書き出しに、紐付けの `outdoorTopos` と画像の `topoPhotos` を含める。画像はJPEGデータURLとして記載し、復元時に形式・大きさ・ハッシュ・参照の充足を検証する。バイナリはIndexedDBへ先に格納し、検証済みの紐付けだけを通常の保存へ渡す。データURLをlocalStorageへ入れない。

同じ課題と同じ写真の紐付けは結合時に重複させず、初期状態では端末のマークを優先。「上書き」を明示した場合のみ置き換える。古いバックアップに写真項目がなくても現在の写真は保持する。参照先写真が不足するバックアップは復元を停止する。

JSON取り込みは100MB、書き出し時の写真合計は65MBまで。上限や写真の欠損時に、画像を黙って省いたバックアップは出力しない。日常操作にバックアップを要求しない。サイトデータ削除・端末紛失からの自動復旧はなく、ブラウザーとホーム画面アプリで保存領域が共有されるとは限らない。
