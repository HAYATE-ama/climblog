# トレーニング10コースと動作ガイド

## 選択・実行

トレーニング → 自分で作る → テンプレートから作るから、筋トレ4・柔軟3・ウォーミングアップ2コースを選択します。コースはアプリ独自の編集可能なテンプレートです。初期値は個別の処方ではなく、開始前に経験・体調・道具に合わせて調整します。

- 筋トレ: 指トレ・オープンハンド（足補助）、指トレ・ハーフクリンプ（足補助）、体幹・姿勢づくり、引く力・肩まわり
- 柔軟: 股関節・足上げ、肩・背中・上半身
- ウォーミングアップ: 道具なし・登る前の準備、ゴムバンドで準備

各コースに必要な道具を表示。種目・回数/秒数・セット数・休憩は既存の設定画面で変更でき、「いつものメニュー」への保存にも対応します。コースの定義は実行用コピーから独立しています。

## 動作の説明

コース全種目に、一般名/日本語補足、一言説明、3段階のやり方、注意点、左右の区別、1回の数え方、参考先リンクを用意。設定時・実行中・保存後の読み取り専用詳細で確認できます。過去に保存した種目名を一括変更せず、表示名として一般名を添えます。未知のカスタム種目には推測した説明を生成しません。

説明済み26種目に、オリジナルの2姿勢の模式図を用意。選択カード・テンプレート・作成後の一覧・実行画面で共通の図を使います。未対応・自作種目は図なし表示で利用できます。写真や動画は転載していません。図は簡略化したもので、個々人のフォーム評価ではありません。

左右を分ける種目は種目名末尾の「（左）」「（右）」を使い、独立したタイマーと実績にします。同じセッションとしてカレンダーでまとまります。バードドッグは左手+右脚→右手+左脚で1回と明記。易しいクライミングは時間で完了せず、準備できたら手動完了。1回は準備一式の完了で、課題数ではないことをガイドに明記します。

## 検証

単体テスト174件成功。10コース/3分類、全種目のガイド、未知・不正な名称の処理、左右別タイマー/保存、交互回数、手動完了、姿勢図、保存メニュー/バックアップ互換性、保存後の説明を確認。

climbing-courses.mjsのブラウザーテストでPC1280px・スマホ390px/320pxの選択・ガイド・図・左右切替・記録保存・元メニュー無変更・手動完了・テーマ・横はみ出しを確認。usual-training、workout、workout-fields、record-view、settings-drawer、auth-session、pwaの回帰も確認。入力用スクロール余白は画面全体ではなく入力欄のみに適用し、設定の位置復元と両立させました。

ローカルサンプル・模擬認証を使用し、本番の個人記録を操作していません。iPhone実機、運動フォームの専門家による個別評価は未実施です。DBスキーマ変更やAI通信は追加していません。

## 自宅で全身・静的ストレッチ
柔軟カテゴリに追加。マットだけで行える合せき、お尻、股関節前面、背中、前腕を10項目（左右別）で実施します。各20秒保持、保持時間の合計は3分20秒。準備・移行時間は別です。秒数・休憩は編集可能で、いつものメニューに保存できます。
軽く身体を動かした後や運動後の落ち着いた時間に、呼吸を続け、反動をつけず無理のない範囲で保持します。痛みが出る場合は中止してください。登る直前の動的ウォームアップとは別のコースです。参考：NHSの運動後ストレッチ資料（上記）。
