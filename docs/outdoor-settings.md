# 外岩の候補日設定

歯車 → 外岩の候補日。岩場名（1か所・100文字以内）、都道府県、行ける曜日、活動開始・終了（日本時間・当日中）を登録する。岩場名を空欄にして保存すると対象の指定を解除できる。

保存先は既存のアカウント別 preferences.outdoorPlanning。既存のクラウド同期、JSONバックアップ・設定復元の対象となる。テーマ・週の開始設定と併存し、過去の記録は変更しない。保存ボタンで確定し、未保存で戻る・閉じる場合は破棄を確認する。

予報地域を追加し、気象庁の天気と候補日をカレンダーに表示する。旧設定は予報地域の選択後に利用できる。AI/MCPは使用しない。取得・条件・制約は [天気連携](outdoor-weather.md) を参照。
