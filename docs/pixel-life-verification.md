# 追加機能の検証（2026-10-25）

本番アカウント・Supabaseへの読み書きは実施していません。テスト用ローカルHTTPサーバー、隔離したChrome、モックのSupabaseクライアントで検証しました。

- `node --test tests/*.test.mjs`: 42ケース成功。セット別集計、ネストした下書きの独立性、左右挙上重量、メニューのID/日付/体重除外、絶対時刻のタイマー、編集前後スナップショット、ゴミ箱復元、ロールバック、JSON検証・重複、アカウント別初期化、ストレージ失敗時の巻き戻し、従来の機能を含みます。
- ブラウザー: 1280×1000、390×844、320×740。セットの追加・一括項目の再編集・リロード後の下書き復元・通常入力への切替・メニュー保存/適用・左右同時保存・条件プリセット・日誌保存/再表示・タイマー一時停止/再開/リロード・削除/復元/履歴戻し・JSONプレビュー/重複排除を通し操作。JavaScript例外なし。
- 既存画面の回帰: 一括登録、過去記録の体重スナップショット保持、敗退、前回コピー、日付/アカウント別下書き、ホームからの遷移、単一身体保存、文章の目標、今日の強調、ライトテーマの文字コントラストを確認。
- モッククラウド: 旧記録の移行と保持、身体情報、5つの新コレクションの同期、JSON出力を確認。入力途中の下書きがクラウドに混入しないことも確認。
- PWA: manifest/アイコン、Service Workerの有効化、静的ファイルキャッシュ、認証付き私有データのキャッシュ除外、初回有効化での勝手な再読み込み防止をローカルChromeで確認。
- スクリーンショットを確認して、ダーク/ライト、スマホ幅での横はみ出しと入力欄を検査。

iPhone実機のSafari、実際のホーム画面インストール、実Supabaseを使った複数端末間同期、画面を閉じた状態での音は未検証です。同期と認証はオンラインで利用してください。Service Workerは完全なオフライン認証を提供しません。

ブラウザー用スクリプトは `tests/browser/pixel-life.mjs` と `tests/browser/pwa.mjs` です。任意の開発用フォルダにPlaywrightをインストールし、`CLIMBLOG_PLAYWRIGHT_MODULE` にそのパッケージの絶対パス、`CLIMBLOG_BROWSER` にChrome/Chromiumの実行ファイルを指定できます。`node tests/browser/pixel-life.mjs` で実行します。テスト結果と画像はOSの一時フォルダに出力し、アプリの実データは使用しません。
