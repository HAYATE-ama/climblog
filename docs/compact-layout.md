# コンパクトな記録一覧

## 変更内容

- 検索・日別記録・外岩の統計で共通の表示関数を使用。
- 外岩の主行は「場所・課題名・グレード」。長い場所/課題名は省略し、詳細画面と読み上げ名には全文を保持。
- ジムはジム名・保存時の色/グレード、通常トレーニングは種目・実績を優先。
- セットごとの実績が異なる場合は合計回数/秒数、重量は範囲を表示。均一なセットとして誤表示しません。
- 検索は同日でも選択した記録IDの詳細を開きます。日付もカレンダーへ反映。
- 一覧から編集・削除ボタンやメモを外し、詳細画面へ集約。確認付き削除とゴミ箱復元を維持。
- ジム・トレーニングのまとめ、今月のサマリー、設定、トレーニングのメニュー選択のスマホ用余白を整理。
- 活動で絞り込んだ検索では同じ活動名を繰り返さず、全活動検索では表示。表示年が異なる記録の日付には年を残します。
- タイマー、入力、グラフのサイズと処理は維持。既存データやスキーマは変更しません。
