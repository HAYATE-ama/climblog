# トレーニング画面の整理

機能・保存形式は維持。入口にはいつものメニューだけを表示し、テンプレートは作成画面にまとめます。
確認画面は種目名と運動量の一覧。各行を開くと種目変更・動作説明・並べ替え・削除・自分の種目追加・進め方・共通値・セット別設定を編集できます。複数セットで値が異なる場合は「セット別」と表示し、重量があれば併記します。単一セットは使用されないセット間休憩を表示しません。
日付・場所・準備秒数・種目間休憩・音は「記録・タイマー設定」に集約。保存を主ボタンにし、その下に保存せず開始するボタンを置きます。新規種目は自動で編集欄を開きます。通常の変更では開閉状態を安定した種目IDで維持し、別画面へ移った際はリセットします。

検証：122件の単体テスト、新レイアウト、既存のトレーニング実行、いつものメニュー、コース、日付入力のブラウザテスト。PC・スマホ幅320〜1280px、ライト・ダーク。ブラウザテストはローカルのサンプル記録で実施し、本番DBを変更しません。iPhone実機は未確認。

## いつものメニューだけの入口
最初の画面には保存済みメニューと「＋ 自分で作る」のみを表示します。未登録時は「メニューがありません」を表示。作成画面で「一から作る」「テンプレートから作る」を選び、テンプレート画面には筋トレ・柔軟・ウォーミングアップ・基本メニューの4分類を縦に並べます。保存後は一覧へ戻り、既存メニューの編集保存では同じIDで更新します。テンプレートは保存せず開始することも可能です。戻るボタンは作成手順内で一段戻り、入口からは元のカレンダーなどへ戻ります。
実施済み記録はカレンダーの「登録する」から入力。独立した休憩タイマーは実行画面の「補助タイマー」に移動し、開くと実行中のトレーニングは一時停止します。自動休憩・準備カウントダウン・途中再開・保存形式は維持します。
追加検証：usual-menu-entry ブラウザテストで未登録/登録済み、テンプレート4分類、戻る、保存後の一覧、安定ID更新、再読込、補助タイマーによる一時停止をPC/スマホ幅・両テーマで確認。
