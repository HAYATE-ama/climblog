# トレーニング画面の整理

機能・保存形式は維持。いつものメニュー、おすすめコース、折りたたみ式の基本メニュー・その他の使い方に分けます。
確認画面は種目名と運動量の一覧。各行を開くと種目変更・動作説明・並べ替え・削除・自分の種目追加・進め方・共通値・セット別設定を編集できます。複数セットで値が異なる場合は「セット別」と表示し、重量があれば併記します。単一セットは使用されないセット間休憩を表示しません。
日付・場所・準備秒数・種目間休憩・音は「記録・タイマー設定」に集約。開始を主ボタンにし、保存はその下に置きます。新規種目は自動で編集欄を開きます。通常の変更では開閉状態を安定した種目IDで維持し、別画面へ移った際はリセットします。

検証：122件の単体テスト、新レイアウト、既存のトレーニング実行、いつものメニュー、コース、日付入力のブラウザテスト。PC・スマホ幅320〜1280px、ライト・ダーク。ブラウザテストはローカルのサンプル記録で実施し、本番DBを変更しません。iPhone実機は未確認。
