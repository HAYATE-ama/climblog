# 指トレのコース

トレーニング → 自分で作る → テンプレートから作る → 筋トレに追加。

- 指トレ・オープンハンド（足補助）：足補助ハング（オープンハンド）
- 指トレ・ハーフクリンプ（足補助）：足補助ハング（ハーフクリンプ）

各コースの編集用初期値は5秒保持×3セット、セット間休憩60秒、追加重量0kg、開始前5秒。効果や個人への適合を検証した処方ではない。全身と指を十分にウォームアップした後に、両足の補助で負荷を調整する。ハングボードに慣れていない場合や痛みがある場合は、コーチ等に確認する。限界保持・小エッジ・全体重・追加荷重を初期値にしない。保持秒数や休憩は既存の画面で編集可能で、タイマーと一括記録、保存済みメニュー、順番変更の仕組みを使う。

準備の案内は種目ガイドに保持し、コピー・保存後も該当種目を含むメニューの開始前に表示。各カードと実行画面で握り方・足の使い方を確認できる。図は両足接地の全身模式図で、指関節の角度を示す図ではない。握り方の違いは文章を参照する。

種目は安定ID assistedOpenHang / assistedHalfCrimpHangを追加し、既存の「ハングボード（通常）」と区別する。旧記録の握り方を推定したり名称を変更したりしない。負荷の個人差が大きいためrequiresLoadReview=trueでAI自動提案候補から除外する。マスターバージョン2。標準選択55種＋旧整理運動1、ガイド25種、AI提案可能な説明済み種目23種。
