# 豊田ボルダーのグレード

2026-11-21追加。外岩のボルダーで「豊田式（a・b・c…）」を選べる。通常の日本段級、V Scale、Fontainebleau、リードの体系は維持する。

## 操作

- 新しい外岩記録・登りたい課題で岩場に「豊田」を入力すると、保存済みの形式指定がなければ豊田式へ切り替わる。「豊田ボルダー」「豊田ボルダリング」「豊田市」も初期候補として扱う。それ以外の表記は「グレード体系」で明示的に選べる。
- a〜gのボタンで選ぶ。「表記を入力」で、h、f+などトポに記載された表記を12文字まで入力できる。新しく入力した文字は小文字にする。「未設定に戻す」も選べる。
- 記録または登りたい課題を保存した時点で、その岩場・種目のグレード体系を端末に記憶する。形式を日本段級に変えて保存した場合は、次回もその選択を優先する。入力中のキャンセルでは形式設定を保存しない。
- 既存記録・登りたい課題から開く場合は保存済みの表記を優先する。下書きの復元でも保存済みの表記を保持する。過去の記録を一括変換しない。

## データと統計

既存の `gradeSystem`、`outdoorGrade`、`grade` に保存し、新しい記録形式は作らない。岩場ごとの形式は `preferences.outdoorGradeFormats` に `cragName / discipline / system` の配列で保存する。記録・形式設定は既存の一括保存処理で確定する。

豊田式は専用のグレード別グラフで新規完登・再登を表示する。段数へ換算せず、日本段級の最高グレードやシーズンの合計段数には加算しない。完登の課題数と回数には含める。体系未設定の過去の「f」等を、文字だけで豊田式へ変更しない。

記録詳細、登りたい課題、写真・トポでは保存された文字をそのまま表示する。相談用レポートにもグレード体系と外岩グレードを含め、分析時に段級と混同しない。レポート作成だけで外部送信はしない。写真・トポの紐付けはグレードに依存しない。

既存JSONバックアップで記録を復元できる。岩場ごとの形式設定を取り込む場合は、復元時に設定の復元も選択する。古いバックアップに形式設定がなくても問題ない。

## 換算しない理由・資料

山と溪谷社『日本100岩場』に基づく説明では、従来のfを二段以上とする扱いと、新規開拓エリアでe・f・gを使用する扱いが併記されている。同じ文字から一意に段数を決めない。a〜gは選択を簡単にする基本候補であり、全課題の表記を網羅した一覧ではない。
