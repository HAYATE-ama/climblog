# グレード別サーキットの使い方

カレンダーで日付を選び、「トレーニングを開始」→「グレード別サーキット」を開きます。ジムと登るグレードを選びます。グレードの名前・色は、そのジムの設定を使います。

- **番号のジム**　たとえば全12課題なら、総課題数に「12」を入れ、「1番からの番号を並べる」で開始します。一覧の「8番」をタップし、「完登 ＋1」または「途中落ち ＋1」で結果を記録します。
- **飛び番・テープのジム**　「番号・テープを個別に追加する」で開始します。「＋ 課題を追加」から番号（例「3、8、12」「1-12」）またはテープの形を選びます。「その他」は自由入力です。同じ形が複数あれば「壁・位置」で区別します。同じ種類・目印・位置を再登録すると、元の課題が選ばれます。番号とテープは同じ一覧で使えます。
- **総数が不明なとき**　総課題数を空欄にし、登る課題から追加します。総数が判明したら、実施画面の「サーキットの設定」で変更できます。

課題を登録しただけでは実績は増えません。完登後も両方のボタンを何度でも押せます。完登した課題数・延べ完登回数・途中落ち回数を分けて表示します。12課題を3周すべて完登すると、12課題・延べ36完登です。周の切り替え操作はありません。2回落ちて3回目に完登したら、その課題は「完登1・トライ3」です。「未完登のみ」で残っている課題を絞り込めます。押し間違いは「直前のトライを戻す」で取り消せます。

途中で閉じても、同じ端末で開き直すと途中記録を再開できます。「ここまでで終了」で内容を確認し、「カレンダーに保存」を押すと、トライした課題が1課題1件のジム記録になります。保存後は通常のジム記録と同じ方法で閲覧・編集できます。

## 登攀とレストを分ける（2026-11-20）

新しいサーキットでは「登攀とレストを計測する」がオンです。オフにすると以前と同じ回数のみの操作ができます。

1. 課題を選び、「トライを開始」を押します。赤い表示で今回の登攀時間を計測します。
2. 「完登 ＋1」または「途中落ち ＋1」を押すと、結果を保存し、緑のレスト計測へ切り替わります。
3. 次のトライを開始するまでをレストとします。移動・順番待ちも含みます。失敗したトライも登攀時間に含めます。
4. 全課題を1回ずつ完登した時点の、登攀・レスト・合計時間を保持します。その後も同じ課題を何度でも記録できます。
5. 「ここまでで終了・確認」で結果と備考を確認し、カレンダーに保存します。

備考はサーキット全体と課題ごとに入力できます。入力途中も端末へ自動保存します。全体の備考と時間は、サーキットの「履歴・時間の変化」またはカレンダー内の「サーキットの時間・備考を見る」から確認できます。課題ごとの備考は通常のジム記録のメモにも保存します。

## 同じ課題での比較

「履歴・時間の変化」から記録を開き、「同じセットで始める」を押すと、課題の構成を引き継ぎます。日付はカレンダーで選択中の日付です。回数、時間、備考は空から始めます。現在のサーキットがある場合は、先に保存または破棄してください。

ジム・グレード・課題セットID・課題の目印/壁位置・総数が同じ場合だけ比較します。番号が同じでもホールド替え後は新規セットを作成してください。課題追加や総数変更時は別セットになり、計測途中なら今回の比較を無効にします。総数不明の間は「全課題完登」を判定しません。2周目以降の到達点は「全課題を各N回完登」という累計であり、登った順序を保証するものではありません。

一時停止時間は登攀・レストから除外し、別に保持します。途中開始・一時停止・確認画面からの再開・未確定の終了トライ・時計の逆行/1日超の空白がある記録は、比較対象外です。終了時に未確定のトライを完登や途中落ちへ自動変換しません。レストが短いほど良いと評価したり、短縮を促したりはしません。

## 保存と互換性

- 既存v1/v2の下書きは引き続き読み込めます。時間のない過去記録に時間を補いません。旧下書きへ途中から計測を追加した場合は比較対象外です。
- タイマーは保存した時刻差から計算し、画面の閉鎖、背景化、再読み込みでも経過時間を回収します。OSがJavaScriptを止めている間に画面や音を更新できる保証はありません。この機能はストップウォッチであり、レスト終了の通知音は追加していません。
- 通常のジム記録と、全体の備考・計測・課題構成のスナップショットを、既存の端末保存トランザクションで同時保存します。スナップショットは既存の `workoutReceipts` 内の `circuitSession` に置き、JSON書き出し/復元にも含めます。新しい外部送信はありません。
- 保存IDで二重保存を防止し、複数タブの下書き書き込みはロックと保存内容比較で保護します。備考保存に失敗した場合は未保存内容を保持し、後続操作の前に再保存します。
- 元のジム記録に編集・削除があれば保存時の結果をその旨付きで表示し、時間比較から除外します。全対象記録を削除したセッションは履歴に表示しません。ゴミ箱から戻せば再表示されます。

検証はサンプルデータによる単体・ブラウザー試験です。iPhone実機、OSの強制終了や端末時計変更の実機試験とは区別します。
