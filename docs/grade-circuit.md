# グレード別サーキットの使い方

カレンダーで日付を選び、「トレーニングを開始」→「グレード別サーキット」を開きます。ジムと登るグレードを選びます。グレードの名前・色は、そのジムの設定を使います。

- **番号のジム**　たとえば全12課題なら、総課題数に「12」を入れ、「1番からの番号を並べる」で開始します。一覧の「8番」をタップし、「完登 ＋1」または「途中落ち ＋1」で結果を記録します。
- **飛び番・テープのジム**　「番号・テープを個別に追加する」で開始します。「＋ 課題を追加」から番号（例「3、8、12」「1-12」）またはテープの形を選びます。「その他」は自由入力です。同じ形が複数あれば「壁・位置」で区別します。同じ種類・目印・位置を再登録すると、元の課題が選ばれます。番号とテープは同じ一覧で使えます。
- **総数が不明なとき**　総課題数を空欄にし、登る課題から追加します。総数が判明したら、実施画面の「サーキットの設定」で変更できます。

課題を登録しただけでは実績は増えません。完登後も両方のボタンを何度でも押せます。完登した課題数・延べ完登回数・途中落ち回数を分けて表示します。12課題を3周すべて完登すると、12課題・延べ36完登です。周の切り替え操作はありません。2回落ちて3回目に完登したら、その課題は「完登1・トライ3」です。「未完登のみ」で残っている課題を絞り込めます。押し間違いは「直前のトライを戻す」で取り消せます。

途中で閉じても、同じ端末で開き直すと途中記録を再開できます。「ここまでで終了」で内容を確認し、「カレンダーに保存」を押すと、トライした課題が1課題1件のジム記録になります。保存後は通常のジム記録と同じ方法で閲覧・編集できます。
