# トレーニング入力とデータの改善（2026-10-28）

## 今回の改善

1. 開始前のメニュー編集を、アカウント別の端末内下書きへ保存する。いつものメニューの「編集を再開」から復元できる。
2. 指トレのカードにだけ「握り方・エッジ（任意）」を追加。初期状態は折りたたみ。握り方、エッジ深さを左右のカードごとに記録できる。
3. コースの重量の未設定と、本人が入力した0kgを区別する。空欄へ戻す操作も可能。加重／地面リフトで未設定のセットがあれば、開始時に該当カードへ案内する。
4. 種目・左右・進め方・荷重方法に加え、握り方・深さが異なる記録を将来のAI用集計で分ける。
5. 開始前・実行中・結果確認・保存後の閲覧で、設定した握り方と深さを確認できる。メニュー保存、途中記録、カレンダー記録、再利用、JSONバックアップへ引き継ぐ。
6. タイトル／場所の有効な入力と、同じ重量を使うカードの重量入力は、入力中も保存する。その他の構成変更は有効な変更の確定後に保存。全セットの上書き確認は維持する。
7. 入力後にボタンへ移るとき、入力欄の再描画で最初のタップが失われる問題を改善する。

## 下書き

`WorkoutSetupStore` は `climbLogWorkoutSetup:<accountId>` の1件を扱う。実行中タイマーの `climbLogWorkoutDraft:<accountId>` と分離。保存するのは検証済みのメニュー、日付、元メニューID、戻り先のみ。クラウドへは送信しない。

- 編集した内容があるときだけ、いつものメニューへ再開／破棄の操作を表示。
- 別メニューへ置き換える場合と、下書きの明示破棄は確認する。
- 保存済みメニューを選んで編集しても「いつものメニューに保存」までは保存済みの内容を変更しない。
- 保存成功、または実行中の途中記録を作成できた後で下書きを片づける。
- 読み込めない下書きは実行せず、無断で上書きしない。本人が破棄を選べる。
- 同じアカウントの別タブで下書きが変わった場合は上書き・削除を止め、最新内容の確認を案内する。
- 端末保存が失敗したときは画面に通知する。保存されない値や入力エラーを含む未確定の文字列まで完全に復元する保証はない。
- この端末だけの下書きであり、別端末からの再開には対応しない。保存済みメニューと活動記録は従来どおりクラウド保存。

## 指トレの条件

正本は `training-conditions.mjs`。メニュー内の各種目に `fingerConditions:{gripType,edgeDepthMm}` を任意追加する。

- gripType：open / halfCrimp / fullCrimp / null。
- edgeDepthMm：0.1〜100の数値またはnull。数値範囲は入力保護であり、推奨する負荷・深さではない。
- 足補助ハングの握り方は種目の正本に合わせ固定。例えばオープンハンドの種目をハーフクリンプとして保存しない。
- 種目を変更したときは前の条件を外す。同じ種目をカードで選び直した場合は条件を維持。
- 完了した実績にはgripTypeとedgeDepthMmをスナップショットとして保存。過去の記録を現在の設定へ書き換えない。
- 条件は任意。未設定と既知の条件を同じ条件として集計しない。今回の範囲では自作種目へ指トレ条件の専用UIは追加しない。

## 重量

セットの `loadRecorded` が true の0kgは明示的な0kg、falseは未設定。従来の数値 `loadKg` は互換性のため保持する。空欄へ戻すと数値は0、設定状態はfalseにする。

- 既存の正の重量は数値を維持する。
- 明示的に自重を選んだ追加重量0は、重量なしとして扱える。
- 古い加重／リフトの0kgは、入力済みとは推測しない。再利用して開始するときに確認を求める。
- 新しいコースで加重／リフトを使う場合、全セットの重量を入力してから開始。重量を使わない場合は自重へ切り替えられる。
- 自重への切替時、正の追加重量がある場合は確認し、0へ変更する。過去の保存済み記録は変更しない。
- 未設定の重量は平均や最小／最大のサンプルから除外。保存済みの閲覧では「未記録」と表示。
- 既存の手入力フォーム等の、設定状態を持たない古い0kgを一括して書き換えない。今回、明示的な状態管理と開始確認を導入した主な対象はトレーニングのコース編集画面。

## 将来のAI用データ

`routineExercises` は条件別の集計を保持する。`trainingDataQuality` に、重量が未確認の記録数と、握り方・エッジ深さが揃った指トレの記録数を追加。自由記述や利用者IDはこの集計へ混入しない。実API・課金・新しい外部送信は追加していない。

## 0kgの表示
入力済みの0kgは「重量なし」へ自動で表示を変換する。編集用の数値欄と保存・計算の値は0を維持。空欄は未設定、過去の未確認値は未記録として区別する。荷重方法や体重を0へ変える処理ではない。カード・実行・結果・閲覧で同じ表現を使う。
