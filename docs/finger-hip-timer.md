# コースとタイマーの使い方（2026-11-06）

## コースの選択
カレンダーのトレーニング → 新しいメニュー → テンプレートから選ぶ、で曜日・用途を選ぶ。
- 毎日：股関節・足上げ、上半身、家の静的ストレッチ。すべてを毎日こなす必須課題ではなく、軽い柔軟の選択肢。
- 火曜：指の最大筋力A（ハーフクリンプ）または静かな足のテーマ練習など。
- 木曜：指の最大筋力B（オープンハンド）またはムーブパズルなど。
- 土日どちらか：本命課題の集中トライやウォームアップ。外岩の実施課題・完登は別途記録する。

火曜・木曜の高負荷の指トレと限界登りをすべて重ねる指示ではない。疲労や週末の予定に応じて選び、必要なら登りを軽くする。曜日フィルターは予定の提案で、自動実行・記録・通知はしない。

## 指の保持と柔軟
片手の地面からのリフト保持は左右別、3秒×3セット、セット間180秒。段階的な準備を手動で完了してから進む。重量とエッジを確認して使用する。重量は未設定で作成し、過去の瞬間的な挙上重量から自動設定・増量しない。無理なく静止して下ろせる重量を個別に選ぶ。痛みや違和感があれば中止する。

最大値の記録では、瞬間挙上と秒数を指定した保持を選び分ける。過去の未設定条件は未設定のまま残し、異なる方式・保持秒数・握り・エッジ・左右の最大値を混ぜない。通常の保持コースの完了を最大値測定として自動登録しない。

股関節コースは支え付き開脚を含む約6分（動作4分＋休憩・切替）。膝を曲げてもよく、開脚の深さを競わない。これは個人に最適な負荷・改善速度を保証するものではない。

## バックグラウンドと音
- 秒数制の運動・休憩・準備は終了予定時刻で進む。画面を離れて戻った際は、経過した段階まで進める。
- 回数制は手動の完了が必要。一時停止と認証切れでは進まない。
- バックグラウンドで遅れて進行を反映した場合、保存前の確認に注意を表示する。実施していないセットは0へ修正してから保存する。経過だけでカレンダーへ自動保存しない。
- 再読み込み・アプリの終了後は途中記録の確認と明示的な再開が必要。アプリがOSから終了された後も自動実行するものではない。
- 開始・再開の操作で音声を有効にし、残り3・2・1秒と切替音を鳴らす。音を確認ボタンで中断した音声の接続を作り直せる。休憩タイマーにも確認音を用意。
- バックグラウンド用の音は最大30分先・64個まで先に予約する。ただしiPhone/PWAを含むOS・ブラウザーの制限により、画面ロック中・別アプリ利用中の音声は保証できない。音が止まった場合は画面を戻し、メディア音量・消音設定を確認して音を確認を押す。
- 音声再生不可でも視覚表示と時計は利用できる。通知権限や無音の連続再生に依存しない。
