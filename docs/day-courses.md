# 一日の完成コース

通常版と短縮版がある8コースと、日常の股関節コースを追加する。内容はユーザーと相談した試行用の開始案で、個人に最適化された処方や固定の16週間プログラムではない。曜日・期間の自動進行、欠席分の繰越、自動増量は行わない。高負荷練習は普段の登攀の一部と置き換える。

## 定義と実施

正本は assets/js/day-courses.mjs。各コースに安定ID、version、目的、器具、時間目安、強度と終了条件、通常/短縮の種目順序を持つ。種目名・左右・器具はexercise-registry.mjs、動作説明はexercise-guide-data.mjsを参照する。

| ID | 内容 | 通常版の主練習 | 短縮版の主練習 |
|---|---|---|---|
| day-finger-strength | 指の力を伸ばす日 | 3秒×左右3セット、技術4課題×2本、補強3種×左右 | 左右2セット、技術4本、補強省略 |
| day-power | 遠い一手を伸ばす日 | 2種類×3トライ、易しい課題3本、股関節 | 1種類×4トライ、易しい課題2本 |
| day-crux-link | 核心をつなぐ日 | 必要時の単体確認最大3回、6〜12手×4トライ | 単体確認は必要時1回、連結3トライ |
| day-long-route | 長ものを登る日 | 12〜20手×3トライ、股関節 | 長もの2トライ |
| day-repeat-quality | 良いトライを繰り返す日 | A/Bを交互に各3本、補強3種×左右 | A/B交互に計4本 |
| day-roof-technique | ルーフと足技を磨く日 | 出口2区間×3トライ、技術3課題×2本、股関節 | 出口1区間×3、技術2課題×2本 |
| day-light | 軽く整える日 | 連続3分×2、易しい課題3本、股関節 | 連続3分×1、易しい課題2本 |
| day-outdoor | 外岩で成果を狙う日 | 現地確認、準備、観察、本気トライ最大3回の開始案 | 同じ準備、1〜2回まで |
| daily-active-hips | 使える股関節を作る | 左右重心移動6回、90/90各5回、膝上げ各5回・各3秒、高足移動各5回 | 同じ4動作を各3回の試行案 |

通常/短縮でウォーミングアップを変えない。準備25分、軽い日15分は手動完了の目安であり、自動的に準備完了にしない。時間の範囲はユーザー案であり、タイマーの合計から算出した保証ではない。

左右リフトは左→右を3周（短縮2周）。各保持は3秒で、その後90秒休むため、同じ手の終了から次の開始まで183秒以上になる。最後のリフト後は技術練習への移行に120秒を置く。重量とエッジは未設定、握りは開始前にその日1種類を選ぶ。瞬間的な最大測定値を持続保持へ換算しない。

本数は失敗した試行も含み、完登数ではない。外岩は固定した休憩タイマーや3回の消化を要求せず、本人が毎回回復と現地条件を判断する。すべてのコースは実施後の振り返り・実績確認へ進む。

股関節の組込みは日常コースの3番（膝上げ3秒）・4番（低い台での高足重心移動）で、同日に実施済みなら重ねて要求しない。日常コース自体も毎日の義務にしない。

## 既存との対応

新しい指コースにfinger-max-half/open、技術コースにsilent-feet/movement-puzzle、外岩コースにproject-focusを対応づける。ただし同一処方とはみなさない。旧定義を残し、新規選択では重複候補を隠せるsupersededCourseIdsを提供する。保存済みメニュー・旧セッション・記録は移行削除せず保持する。足補助ハング、動的リフト、静的柔軟、体幹、引く力、単独ウォームアップなど独自目的の旧コースは別の目的として保持する。

種目は20件を追加し、既存65件のID・名称・左右の意味は維持する。既存の両腕バンド外旋と新しい片腕外旋は別ID。新しい既定種目を旧AI候補に自動で追加しない。

## 実施・保存の連携
入口は「その日のコースを選ぶ」と保存済みの「いつものメニュー」。旧5コースは選択一覧から外し、独自目的の10コースと保存済みメニューは保持。保存済みメニューを一括変換せず、旧IDを新IDに同一視しません。

通常/短縮切替は編集内容を初期化するため確認を表示します。開始前は痛み・疲労・時間（未定可）・近い外岩を明示確認。値をメニューへ保存して次回の体調として流用しません。高負荷を個別最適と判定する処理、曜日固定、期間の自動進行、外部AI通信はありません。

新コースはタイマー計測と実績を分離。時間経過・手動の進行操作だけではactualを埋めず、結果を明示入力して確定します。失敗した試行は1本、スキップは実績0。途中終了時の現在セットも未確定入力対象として残します。運動中の直前入力、終了後の編集、前の実施へ戻る（以降の未保存結果を確認して取消）、再読込からの再開に対応。

既存のrecordsにコースID/版/種類・開始前/終了後・完了状態・処方スナップショット・セット実績を任意項目として追加。workoutReceipts.courseSessionに実施時の全予定と結果を保存します。新しいDBテーブルは不要。過去のコース定義を後から変えても実施時の内容を閲覧できます。

同条件参照は既知の種目ID・左右・方式・目標が一致する確定済み記録のみ。指は握り/エッジ必須、登攀は課題・グレード・区間・開始位置・手数を照合。未知条件を同じと判定せず、瞬間最大測定を持続保持へ換算しません。姿勢等の違いは人が確認します。

保存後は閲覧画面の「編集」からコース実績/成否/詳細/RPE/メモを修正でき、変更前をrecordHistoryに保持。全実績を0にする場合は、無言で削除せず既存の削除操作へ案内します。

バックアップ/同期は既存のアカウント別JSON保存を使用。相談用レポートではコースID/版/予定と実績を出力し、身体状態は身体共有、自由記述はメモ共有、課題名は場所共有に従います。動画参照は自動アクセス・外部送信しません。
