# 縦並び設定ドロワー

歯車から右側の設定ドロワーを開きます。PCは幅420px、スマホは幅90%、360px以下では全幅です。元のホーム・カレンダー・統計・トレーニング画面を切り替えず、背景位置を維持します。

- 項目はPC・スマホとも縦1列: 表示・カレンダー、身体情報、ジム・グレード、データ管理。
- 同じドロワー内で子項目へ移動。戻る操作で親項目へ戻ります。
- 入力ラベルと入力欄も縦並び。ジム設定は小さな幅に収まるよう調整。
- 復元・ゴミ箱・履歴も同じ枠内に表示し、モーダルを重ねません。
- ×、背景タップ、Escで閉じます。背景スクロールを止め、閉じたら元の位置と歯車のフォーカスを復元。
- 身体情報・ジム設定の未保存変更は、戻る/閉じる前に破棄の確認。キャンセルなら編集を継続。ジムの変更破棄はメモリ内の編集内容も戻します。
- テーマと週の始まりは従来通り即時保存。認証ロック時は未保存確認を挟まず閉じます。
- Tab/Shift+Tabはドロワー内で循環。動き軽減設定ではスライドなし。

## 検証

単体テスト103件、およびsettings-drawer.mjsのPC1280px・スマホ390px/320pxテストが成功。縦並び・幅・元画面維持・位置/フォーカス復元・未保存変更の取消/破棄/保存・単一モーダル・背景/Esc/Tab・認証ロック・動き軽減・記録無変更を確認。

既存のcompact-layout、pixel-life、auth-session、coach、quiet-home、record-view、workout、pwaのブラウザーテストも新しい設定導線で確認。テストはローカルサンプル/模擬認証を使用。本番の個人記録やアカウント情報は使用していません。iPhone実機でのSafariとソフトキーボードの挙動は未検証です。
