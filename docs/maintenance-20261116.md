# 外岩リストの未保存入力保護（2026-11-16）

## 再現した課題と改善
「登りたい課題」の追加画面で岩場・課題名を入力した後、Esc・戻る・閉じるを操作すると、未保存入力の破棄を取り消せず、次の追加で入力が消えることをサンプルで再現した。
追加画面を開いた時点の値を控え、入力が変わった場合だけ破棄を確認する。取消なら追加画面と入力を維持する。明示的に破棄すれば一覧へ戻るか閉じる。入力前の戻る、一覧・詳細の移動、保存成功後には追加確認を出さない。認証ロック時は確認を挟まず既存処理で閉じてリセットする。
既存記録やリストの保存形式、課題の完了判定は変更しない。新しい永続保存先や送信先は追加しない。
