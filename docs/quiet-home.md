# 景色を楽しむホームとコハク

2026-11-20更新。採用された修正サンプルに合わせ、ホームの景色を実際のアニメーションGIFに変更した。

## 画面と操作

- 湖・山・テント・岩・鳥のある景色。左上の天気ラベル、景色の上の小見出しと日付を取り除く。
- 見出し、キャプション、「今日を記録する」、ホーム下部の「登りたい課題」「いつものトレーニング」は通常のHTMLで表示する。ボタンを画像に埋め込まない。
- 「今日を記録する」からジム・外岩・トレーニングを開く。既存の入力、下書き、タイマー、保存を使用し、独自の保存経路は作らない。
- 画面全体のナビゲーションと共通の外観は[日々の操作を中心にしたレイアウト](modern-layout.md)を参照。
- 天気と人物の行動は自動で変わる。天気や行動を選ぶ操作、タップによる会話は設けない。
- 一時停止／再生だけを右下に設置。停止時は静止画に戻り、再生時は同じ行動を最初から再生する。停止したフレームからの再開ではない。
- 天気は架空の演出で、実際の予報・気象条件・記録内容には連動しない。画像の代替テキストにも説明する。
- キャプションは状況を短く伝える。頻繁な読み上げ通知は行わず、保存結果は既存の通知で伝える。
- 記録メニューはdetails/summaryを維持。選択肢へフォーカスし、Escape／外側のクリックで閉じる。スマホ・PC、ライト／ダーク対応。

## 自動の行動と天気

4種類の行動をシャッフルして一巡し、巡回の境目でも同じ行動が続かない。行動に対応するGIFをランダムに選ぶ。

| 行動 | 天気のバリエーション | 1本の長さ |
| --- | --- | --- |
| 散歩：歩いて手を振り、キャンプへ戻る | 晴れ・星空 | 9.4秒 |
| テント：入口へ歩き、入って休み、外へ戻る | 雨・雪 | 14.7秒 |
| 岩登り：岩へ歩き、手足を使って登り、降りる | くもり・夕暮れ | 14.7秒 |
| 水泳：岸へ歩き、遠くで泳ぎ、戻る | 晴れ | 16秒 |

7本で4行動・6種類の天気を用意。湖面、テント、雲、雨雪、ランタンもGIF内で動く。1本が終わると次の行動と天気に切り替わる。記録の保存で行動を変更しない。

## 実装・素材・負荷

- `home-screen.mjs`：画面と既存の記録入口。`pixelRoom`はCanvasからimgに変更。
- `pixel-companion.mjs`：一時停止、動き軽減、表示状態、保存通知を扱う。既存の呼び出し元とイベントを維持。
- `home-landscape.mjs`：同じサイトからGIFを取得し、ブラウザーの画像デコーダーで再生。再生ごとにObject URLを作り、終了・停止・再マウント時に破棄する。
- `basecamp-model.mjs`：個人データに依存しない行動とGIFの抽選、各ファイルのフレーム数と長さ。
- `assets/images/basecamp/`：600×360、10fpsのGIF 7本と静止画。GIF合計13,526,371バイト（約13.5MB）。従来の描画用WebPより初回取得量は増えるため、PWA更新の完了を待つ必要がある。
- ホーム実行時にCanvas・WebGL・毎フレームのJavaScript描画を使わない。端末の消費電力が減ることは実測しておらず、保証しない。
- 新たな実行時ライブラリ、AI API、気象API、ユーザーデータの外部送信は追加しない。
- 画面外・別タブ・別画面・pagehide・旧認証解除イベントではGIFを取り外し、静止画を表示。復帰時は同じ行動を最初から再生し、経過時間分を早送りしない。
- OSの「動きを減らす」設定では静止画。利用者が明示的に再生を押した場合は、その画面の利用中に再生可能。OS設定が変われば再度従う。
- 読み込み失敗では静止画と案内を表示し、記録操作を維持。画面切り替えによる自動再試行は行わず、再生ボタンで再取得できる。

## GIFを作り直す場合

承認済みの元画像・フレーム定義・描画コードは`tools/basecamp/`に保存する。開発時にのみCanvasとWebGLでGIFのフレームを描画する。これらとビルドツールはGitHubには含めるが、本番サイトには配信しない。

開発環境にPlaywright、gifenc、Chromeを用意し、`CLIMBLOG_PLAYWRIGHT_MODULE`、`CLIMBLOG_GIFENC_MODULE`、必要に応じて`CLIMBLOG_BROWSER`で場所を指定して、リポジトリルートで実行する。

```text
node tools/build-basecamp-gifs.mjs
node --test tests/basecamp.test.mjs tests/offline-assets.test.mjs
```

生成ではローカルの元画像だけを使い、実AI APIや外部画像サービスを呼び出さない。画像・時間を変更した場合はブラウザーテストとオフライン資源一覧も確認する。

## オフラインと更新

GIFと静止画を静的キャッシュに追加し、Service Workerのキャッシュ世代を更新。初回オンライン取得後はオフラインでも表示・再生できる。更新は従来どおり利用者の確認後に適用し、記録はキャッシュとは別に端末へ保持する。記録領域の削除や初期化は不要。

## 検証

- 単体463件成功。行動の一巡、連続重複の防止、天気の組み合わせ、7本のGIF構造・フレーム数・再生時間・容量、静的資源一覧を確認。
- landscape-home：320／390／1280px × 両テーマ。ジム・外岩・トレーニングへの導線、戻る、キーボード、横はみ出し、記録データ不変。
- quiet-home：3画面幅、実際の画像変化、一時停止／再生、OSの動き軽減、別画面で停止、保存通知。
- basecamp：7本のGIFを実際のimg要素で再生。自動切り替え、動き軽減からの明示的な再生、読み込み失敗、遅延中の画面移動、再マウント、非表示・画面外での停止、Object URLの解放、外部通信なしを確認。
- pwa／pwa-upgrade：GIFを含むオフライン再表示、更新をキャンセルして入力を保持、確認後に更新、保存データ保持と旧キャッシュ除去。
- pixel-life：3画面幅で記録・編集・下書き、メニュー、休憩タイマー、削除と復元、JSON復元をサンプルデータで確認。
- 全て隔離ブラウザーとサンプルデータを使用。本番の記録やアカウントをテストで操作していない。

## 未確認

iPhone実機でのGIF再生、Safari固有の挙動、電池消費、低性能端末での継続的な負荷は未測定。ブラウザーでの画面幅確認と実機確認を区別する。
