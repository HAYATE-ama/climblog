# 景色を楽しむホームとコハク

2026-10-30、主担当とサポート1名で刷新。作業開始22:43:32 JST、30分枠。キャラクターが主役で、情報を詰め込まない方針を維持した。

## 画面
- 室内の山小屋から、山・湖・テント・岩場・小さな鳥がいるオリジナルのドット絵へ変更。既存の主人公のオレンジの帽子と対話を残した。
- 朝・昼・夕方・夜の4配色。日付と時間帯は端末の時計を使用する。天気予報や実際の気象状況を表すものではない。
- 大きな景色、短い一言、「記録する」の入口だけを配置。数値・統計・目標・バッジのカードを再び並べない。
- 「記録する」を開くと、ジム・外岩の記録とトレーニング開始を選べる。既存の入力・下書き・タイマー画面を開き、ホーム独自の保存経路は作らない。
- PCは景色が大きすぎて操作が遠くならないよう幅を調整。スマホでは一列で、ライト／ダークを維持する。

## 動きと操作
- 呼吸・まばたき、ゆっくりした雲と湖面、鳥の小さな動き。
- タップまたはEnter/Spaceで手を振り、短いセリフを切り替える。
- 待機中は歩く・岩に登る・書く・休む仕草。記録後のお祝いポーズと既存の通知を維持。
- OSの動き軽減設定では静止画にし、対話による静止ポーズの切り替えは利用できる。設定変更直後にも静止画へ更新して描画を停止する。
- 別画面・非表示・認証解除・pagehideでは描画を停止する。再表示時に再接続し、描画ループを重ねない。
- 記録メニューはネイティブdetails/summaryを使い、開くと最初の選択肢へフォーカス。Escapeで閉じて戻り、外側のクリックや認証解除でも閉じる。

## 実装・素材
HTML/CSS/JavaScriptとCanvasのみ使用。背景4枚をキャッシュして使い回し、画面表示中のみ既存の約8fpsで動きを更新する。外部画像・有料素材・追加依存・AI API呼び出しは使用していない。既存のpaintRoom、roomPeriod、pixelRoom、companionSpeech、homeRenderedと反応イベントの契約は維持した。
