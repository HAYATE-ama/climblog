# シンプルなホームとコハクの動き

ホームはオリジナルCanvasの山小屋・主人公と短いセリフ1つだけです。目標、最近の記録、数値、バッジ、開始ボタンなどのホームカードを外しました。データは削除していません。目標は設定、記録とトレーニング開始・振り返りはカレンダー、統計とAIコーチは既存のナビゲーションから使用できます。

- 待機中の小さな呼吸・まばたき、雲の移動。
- タップまたはEnter/Spaceで手を振り、短いセリフを切り替え。
- しばらく待つと、壁に登る・書く・休む・少し歩く仕草。
- 記録の保存後は喜ぶポーズとセリフ。ホームに戻った時点で反応時間内なら表示。
- 端末の時刻で朝・昼・夕方・夜の窓の空を変更。
- OSのprefers-reduced-motionでは静止画でポーズと文章のみ切替。非表示タブ・別画面・認証ロックでは描画停止。

HTML/CSS/JavaScriptとCanvasのみ使用し、有料サービス、外部素材、AI通信は追加していません。主人公の操作は記録・身体情報・目標などを変更しません。

## 検証

- 単体テスト95件。
- tests/browser/quiet-home.mjs: PC1280px、スマホ390px/320pxで要素の簡素化、待機アニメーション、タップ・キーボード、保存反応、非表示時の描画停止、動き軽減設定、ライト/ダーク、横はみ出し、データ無変更を検証。朝昼夕夜の描画差分も確認。
- auth-session、workout、record-view、coach、pwa、pixel-lifeの既存ブラウザーテストを、カレンダーなどの残る導線に更新して回帰確認。
- ブラウザーテストはローカルデータ/模擬認証を使用。本番の個人記録は変更していません。iPhone実機の性能・電池消費は未測定。
