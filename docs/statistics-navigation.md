# 目的から選ぶ統計画面（2026-10-28）

## 入口

統計タブには、グラフをすべて並べる代わりに、縦並びの6項目を表示する。

|項目|見られるもの|
|---|---|
|活動全体|登った日、トレーニングした日、活動の推移、種類・曜日別の内訳|
|ジム|完登数、敗退の記録数、記録時のジム・色・グレード別の完登、トライ数|
|外岩|1/1〜12/31のシーズン、完登／トライの記録、岩場・結果の内訳、全記録の並び替え|
|トレーニング量|実施セット、記録済み時間、回数・保持秒、種目と条件別の量、きつさ|
|指・懸垂の最大出力|同一の測定条件での重量の推移、体重比、関連条件での左右差|
|身体の変化|期間内の体重推移と元データ、現在の身長・リーチ、身体設定への入口|

目標・振り返りは入口の末尾で折りたたむ。保存機能・文章形式は維持する。ホーム、カレンダー、記録の保存形式、認証・クラウド同期は変更しない。

## 詳細の構成

どの項目でも「対象期間・条件 → 要点2つ → 主なグラフ → 詳しい内訳（開閉） → 元の記録」の順。戻る操作は直前に選んだ項目へフォーカスを戻す。主なナビゲーションの統計タブは項目一覧へ戻る。

- 活動全体・最大出力・身体は今年、ジム・トレーニングは今月が初期値。
- 外岩は年のシーズンのみ。ほかの画面の月フィルターに引きずられない。
- ほかの項目は月／年／全期間を選べる。月または年を明示的に指定し、実際の開始日と終了日を常時表示する。
- 日付選択はカレンダーの表示月から独立。項目ごとの期間や条件は、そのページを開いている間保持する。再読み込み後は初期値。
- ジムの絞り込みはジムの統計だけに適用。
- 元の記録は30件ずつ追加表示し、すべての件数へ到達できる。外岩も先頭数件で打ち切らない。
- 活動記録の行を押すと既存の閲覧画面を開く。そこから編集・削除を行える。
- 体重の元データは体重履歴。活動記録へ偽のIDを割り当てず、身体情報の設定へ移動して変更する。

## 集計の意味

- 登った日はジム・外岩の記録がある日を重複除去して数える。
- ジムの敗退はgymOutcome=failedの記録。敗退を完登に足さない。グレード名・色は保存時のスナップショットを使い、異なるジムを混ぜない。
- 外岩は安定した課題IDがないため、完登した記録数とトライの記録数として数える。同じ課題を複数日に記録しても、勝手に1課題へ統合しない。結果未記録は完登とみなさない。
- 外岩のトライ数平均は範囲入力の代表値も含むため参考値と明示する。異なるグレード体系の難易度を自動換算せず、グレードの並び替えは表記順。
- トレーニング量から最大出力の測定記録を除外する。時間が未入力の場合は0分の実績として扱わず、記録済み時間と対象件数を示す。
- 種目別の量では、荷重方法、指の握り方、エッジ深さを分離する。平均重量は体重を含まない外部重量。0kgは重量なし。
- RPEはコース全体と種目別で平均を分ける。コース全体の値が複数種目へ保存されていても、同じセッションは1回分として扱う。
- 最大出力は種目、握り方、深さ、保持時間、左右、負荷の基準が同じ群を選択する。条件不足の場合は比較グラフを表示せず、元の記録は確認できる。
- 期間を変えて選択中の測定条件がなくなっても、別の条件を黙って選び直さない。空の状態を表示し、利用者が条件を変更する。
- 最大出力の追加重量のみの群と体重込みの群を混ぜない。同じ日の記録に作成時刻があるときはその順序を利用する。
- 身体の身長・リーチは現在の設定値であり、指定期間の履歴ではないことを明示する。体重は実際に記録した日付の値だけを表示する。
- 折れ線は記録順で表示し、最初・最新の日付と単位を表示する。各測定値は下の一覧で確認できる。

## 実装

- stats-model.mjs：読み取り専用の期間・種類・条件の絞り込みと集計。
- stats-screen.mjs：項目一覧、選択、グラフ、内訳、記録への導線。
- statistics.css：PC／スマホ、両テーマの表示。
- app.jsの以前の巨大な統計描画を分離し、表示中の項目だけを更新。二重の隠れた統計画面は作らない。
- 記録・身体情報・目標などを集計のために書き換えない。表示条件をクラウドへ保存しない。

## 確認

単体テスト207件。うるう年・月末、期間・ジムの独立、活動日の重複除去、敗退、外岩の全シーズン、未入力時間、最大出力の異なる条件／負荷基準、身体の履歴、HTML文字列の安全な表示などを検証。

Chromeの320／390／1280pxとライト／ダークで、6項目の移動、元の記録の閲覧、77件の外岩全件表示、並び替え、測定条件がない期間、身体設定の往復、すべての項目の空状態、表示操作によるデータの非変更を確認。既存の設定ドロワー、コンパクトな記録閲覧、AI画面のナビゲーション、PWA更新時の入力・保存データの保持も確認。

本番の個人記録は試験で変更しない。iPhone Safari実機での確認は未実施。
